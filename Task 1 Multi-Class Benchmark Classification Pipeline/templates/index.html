About IrisScope

Understanding the project and its methodology.

IrisScope

IrisScope is a machine learning classification system designed to predict Iris flower species based on four numerical measurements.

Machine Learning Algorithms

  • Logistic Regression
  • Decision Tree Classifier

Technologies Used

Python, Flask, HTML, CSS, JavaScript, Pandas, NumPy and Scikit-learn.

Classification Categories

  • Iris Setosa
  • Iris Versicolor
  • Iris Virginica
